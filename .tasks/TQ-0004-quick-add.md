## Proposal

Have plus symbols at the bottom of the columns (Trello style) that will allow the user to easily add a new card without having to interact with the full modal.

Clicking on that will show a card with editable title, pressing enter or unfocusing would:
- If the card has content, create a new task.
- If not, discard the card.
